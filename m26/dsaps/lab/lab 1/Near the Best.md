# Near the Best

## Problem Description

You are given a single positive integer `x`. Your task is to find the smallest power of `2` that is greater than or equal to `x`.

In other words, find the minimum value `2ᵏ`, where `k` is a non-negative integer, such that:

```text
2^k ≥ x
```

## Input Format

The first and only line of input consists of a single integer `x`.

## Input Constraints

- `1 ≤ x ≤ 10⁹`

## Output Format

Output a single integer representing the smallest power of `2` that is greater than or equal to `x`.

## Sample Input 1

```text
5
```

## Sample Output 1

```text
8
```

## Sample Input 2

```text
16
```

## Sample Output 2

```text
16
```

## Sample Input 3

```text
13
```

## Sample Output 3

```text
16
```
