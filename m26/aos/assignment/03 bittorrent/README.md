As part of this assignment you will create a complete peer-to-peer file sharing system with tracker servers and client applications. The system allows users to form groups, share files within those groups, and download files by getting different pieces simultaneously from multiple peers. You will be required to implement your own network protocols, multi-threaded downloading, and tracker synchronization mechanisms.
